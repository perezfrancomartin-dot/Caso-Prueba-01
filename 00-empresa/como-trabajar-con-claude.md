# Cómo trabajar con Claude en la empresa

## Lo que Claude puede hacer directamente (desde Claude Code en tu PC)
| Tarea | Cómo |
|---|---|
| Presupuestos, estimaciones de ahorro, planillas | Archivos Excel y PDF en este repositorio |
| Logo, posteos, plantillas de redes | Conector de **Canva** |
| Guiones y prompts de anuncios | En `06-marketing/` |
| Generar videos e imágenes en cantidad | Script que llama a la API de **APIMart** (necesita tu clave en la variable `APIMART_API_KEY`, nunca en el repositorio) |
| Página web (landing) | HTML simple, publicable gratis en GitHub Pages o Netlify |
| Agendar visitas | Conector de **Google Calendar** |
| Borradores de mails a clientes y proveedores | Conector de **Gmail** (siempre como borrador, lo enviás vos) |
| Documentos para Olivia y Gustavo | Conector de **Google Drive / Docs** (ellos no necesitan GitHub) |
| Investigar precios, proveedores, normativa | Búsqueda web |

## Cómo retomar en cualquier sesión
Abrí Claude Code en la carpeta del repositorio y decí, por ejemplo: "Leé CLAUDE.md y la hoja de ruta, y sigamos con la etapa 2". Claude retoma con todo el contexto.

## Para Olivia y Gustavo
El repositorio es para el dueño y Claude. Lo que ellos necesiten (guion de WhatsApp, planilla de consultas, checklist de obra) se comparte por Google Drive.
