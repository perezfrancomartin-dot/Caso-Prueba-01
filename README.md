# Norte Solar

Empresa de energía solar y soluciones eléctricas.

Todo lo de la empresa, ordenado en un solo lugar. Empezá por la **hoja de ruta**.

| Carpeta | Qué hay |
|---|---|
| `00-empresa/` | Hoja de ruta, decisiones, equipo y comisiones, nombre de marca |
| `01-legal-admin/` | Monotributo, matrícula, seguros, acuerdos |
| `02-operaciones/` | Relevamiento, guion de visita, proceso de obra |
| `03-tecnico/` | Guías técnicas y lecciones para aprender |
| `04-compras/` | Análisis de proveedores y precios de equipos |
| `05-ventas/` | Cómo calcular precios, mano de obra y ahorro del cliente |
| `06-marketing/` | Estrategia de Meta Ads, contenido con IA, ganchos y guiones |
| `07-atencion-cliente/` | Guion de WhatsApp para Olivia y calificación de consultas |
| `08-sistema/` | Sistema de seguimiento de clientes y presupuestos automáticos |
| `09-eventos/` | Proyectos especiales (stand solar de fin de año en Mar del Sur) |

`CLAUDE.md` tiene el contexto para que Claude retome el trabajo en cualquier sesión.
